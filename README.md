# NVIDIA Investment Valuation Model
## Overview
A fundamental investment analysis of NVIDIA Corporation (NVDA) developed in Microsoft Excel. The model combines historical financial analysis with valuation methodologies to estimate NVIDIA's intrinsic value and asses sensitivity of the valuation to key assumptions.
## Analysis Included
- Historical financial performance
- Earnings per share (EPS) analysis
- Price to Earnings (P/E) analysis
- Sales per share
- Dividend Discount Model (DDM)
- Discounted Cash Flow (DCF) valuation
- DCF sensitivity analysis
- Valuation summary
## Data
The model uses historical NVIDIA financial and market data, including:
- Revenue
- Net income
- Shares outstanding
- Book value
- Historical share prices
## Valuation
The DCF model forecasts future financial performance and calculates an estimated intrinsic value based on assumptions including:
- Revenue growth
-  Operating margins
-  Tax rate
-  WACC / discount rate
-  Terminal growth rate

Sensitivity analysis is included to evaluate how changes in key assumptions affect the estimated valuation.
